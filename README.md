# Mini Enterprise Linux Lab

## Project Overview

This project demonstrates the design and implementation of an isolated Linux server environment using KVM?QEMU, virt-manager, pfSense, Debian 13, and AlmaLinux.

The lab simulates a small corporate network with segmented management, server, DevOps, DMZ and testing networks.

The project focuses on Linux system administration, network segmentation, firewall configuration, remote adminstration, and network troubleshooting.

## Objectives

* Deploy and manage virtual machines using KVM/QEMU and virt-manager.

* Configure pfSense as the lab's firewall and router.

* Design an IP addressing scheme and segmented virtual networks.

* Configure VLAN interfaces and subnets.

* Deploy headless Debian and Alma servers.

* Configure adn test SSH-based remote administration.

* Impliment least-privilege firewall policies.

* Validate connectivity and isolation between segments.

* Document configuration, testing and troubleshooting procedures.
